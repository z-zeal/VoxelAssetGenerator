How to read this page

Every image is shown 1:1 — one image pixel is one screen pixel, at the same 4 px per voxel across, 2 px down density the runtime blits (previews are frame-0 crops of their baked cells). Nothing is normalised: a 385 px HQ is several times wider on screen than a 47 px rifleman. One map tile is 128 × 64 px covering 32 × 32 voxels, so a voxel is 4 × 2 px. Use the zoom buttons to inspect at 2×/3×; the art is nearest-neighbour, so it stays crisp.

1. Unit scale — true size with ground footprint

Units are drawn at 1:1 on a shared baseline. The dark diamond under each unit is the ground it actually covers; the green diamond inside it is exactly one tile. That is how a 1.75-tile tank differs from a 1-tile rifleman, and how a 2-tile battleship covers four times the ground of an infantry squad.

2. Every unit type at true size

All 58 unit types, drawn 1:1 on the same continuous tile grid and grouped by size class. Each sprite sits on its own tile diamond and the green diamond is exactly one tile, so the hierarchy is readable without any caption: the rifleman rows occupy one tile, the tank/cruiser rows occupy nearly two, and the artillery/battleship rows fill two. The bar at the right of each class heading is that footprint, drawn to the same scale.

3. Unit size — before vs now

The left column reproduces what the previous pipeline produced: the same art resampled into a single 1×1 tile. The right column is the shipped sprite at 1:1 on the same 128×64 tile. Nothing is scaled for display, so the growth is the real change: the tank occupies 56×56 voxels (1.75 tiles) instead of 32×32, the battleship 64×64 (2 tiles) instead of 32×32. The bar under each unit is its footprint measured in tiles.
